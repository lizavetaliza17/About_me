Полный цикл анализа 200 000 заказов: очистка данных (пропуски, смешанные форматы), разведочный анализ, визуализация, бизнес-выводы.

- Обнаружила устойчивую сезонность спроса (пик — декабрь/январь, спад — май–июль)
- Сравнила каналы продаж (Retail/Wholesale/Online) и страны по выручке и среднему чеку
- Задокументировала ограничения анализа (аномалии в данных, длина периода наблюдения)
**Стек:** Python (pandas, matplotlib, seaborn), Jupyter Notebook
